# 🤖 Hisabi Outreach Agents System (نظام الوكلاء الذكي)

هاد المجلد كيحتوي على جميع الوكلاء الذكيين (Agents) المخصصين لجلب العملاء المستقلين (Freelancers) في المغرب وتلقين عملية البيع والتحويل البنكي لـ **Hisabi**.

---

## 📂 أين توجد الملفات؟ (Fin aykono l-agents)
جميع ملفات النظام موجودة هنا في هذا المجلد: `m-insight/hisabi-funnel-agents/`
* **`leadFinder.mjs`**: العميل المكلف بالبحث عن المستقلين المغاربة (Lead Finder).
* **`outreachAgent.mjs`**: العميل المكلف بصياغة العروض الإعلانية بطريقة (Alex Hormozi) وإرسالها عبر البريد الإلكتروني.
* **`inboxManager.mjs`**: العميل المكلف بمراقبة الردود وإرسال معلومات الدفع البنكي (CIH Bank RIB) أوتوماتيكياً لإغلاق المبيعات.
* **`leads.json`**: قاعدة البيانات المحلية التي تحتوي على العملاء المستهدفين وحالتهم.
* **`outbox_simulation.json`**: سجل الرسائل التي تم إرسالها أو صياغتها.
* **`payment_instructions_sent.json`**: سجل العملاء المهتمين الذين أرسلنا لهم معلومات الـ RIB.

---

## 🎮 كيف تتحكم فيهم؟ (Kifach nthkem fihom)
تقدر تشغل كل عميل بوحدو من خلال Terminal باستعمال الأوامر التالية (تأكد أنك داخل مجلد `m-insight`):

### 1️⃣ البحث عن عملاء جدد (Lead Finder)
هاد الأمر كيبحث في محرك البحث على مستقلين مغاربة وكيحفظهم في ملف `leads.json`:
```bash
node hisabi-funnel-agents/leadFinder.mjs
```

### 2️⃣ صياغة العروض وإرسالها (Outreach Agent)
هاد الأمر كياخد العملاء الجداد من ملف `leads.json` وكيصاوب ليهم رسائل مخصصة بالدارجة والمغربية ويرسلها ليهم:
```bash
node hisabi-funnel-agents/outreachAgent.mjs
```

### 3️⃣ الرد بالـ RIB عند اهتمام العميل (Inbox closing)
هاد الأمر كيتأكد من الردود وكيصيفط رسالة فيها معلومات الحساب البنكي CIH ديالك لتفعيل الاشتراك مباشرة:
```bash
node hisabi-funnel-agents/inboxManager.mjs
```

## 📈 كيف تعرف أين وصلنا؟ (Kifach n3ref fin wslna)
لمعرفة حالة الحملة الإعلانية وسير العمل، يمكنك فتح هذه الملفات مباشرة لرؤية التحديثات:
1. **`leads.json`**: كتشوف فيه شكون هما الناس اللي لقينا وحالتهم (`"status": "new"`, `"status": "sent"`, etc.).
2. **`outbox_simulation.json`**: كتشوف فيه الرسائل والعروض اللي تصيفطات وتاريخ الإرسال.
3. **`payment_instructions_sent.json`**: هنا كتلقى العملاء المهتمين اللي وصلاتهم معلومات التحويل البنكي ديالك وفي انتظار إرسالهم لوصل الدفع لتفعيل حساباتهم.
